# jtagram

Este proyecto contiene las reglas comunes que guían a la IA para desarrollar el ecosistema jtagram: frontend, backend e infraestructura. Este repositorio **solo** aloja guías — no código de los proyectos.

## Reglas

- Cada proyecto del ecosistema vive en su propio repositorio, clonado dentro de esta carpeta.
- Siempre que se agregue un nuevo proyecto al ecosistema, hay que agregarlo al `.gitignore` de este repositorio.
